# Hoffmann Toiture

Site web de Hoffmann Toiture, couvreur zingueur à Aulnay-sous-Bois (Seine-Saint-Denis), intervention dans un rayon de 30 km.

Le site est mis en ligne automatiquement avec GitHub Pages à chaque modification du dossier site-web : https://electis-wallonie.github.io/hoffmann-toiture/

Organisation : le dossier site-web contient la page (index.html), les styles (css), les icônes (js) et les photos de chantier (images). Le fichier .github/workflows/deploy.yml gère la mise en ligne.
